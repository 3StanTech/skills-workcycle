# Source register

Where the design and motion rules in these skills came from. Three lists stay apart: **rule sources** (read in full, distilled into our own words, credited), **inspiration sites** (looked at during a round, never distilled), and the **not yet read** queue.

**Adding a source:** paste the link into the queue. Before any rule cites it, a session reads it in full, moves it to Rule sources with the date read and the file the rule landed in, and rewrites the idea in its own words. Post text and attached prompts are never copied (they carry no licence). A rule cites only a source that was actually read.

## Installed outside skills

Eleven skills from `emilkowalski/skills` (MIT), commit `0f2e23b`, installed 2026-11-14: apple-design, animate, choreograph, animation-performance, review-animations, prototype, find-animation-opportunities, improve-animations, remove-animations, gestures, learn-taste. They are optional: the stage skills reach them through the [skill map](../../implement/references/ui-build/motion.md#skill-map), and without them the house rules apply. Install with `npx skills add emilkowalski/skills -g` naming each skill with `-s` and at least two agents with `-a` (with one agent the CLI copies into that agent's folder instead of linking from `~/.agents/skills`); update with `npx skills update -g`, since they are kept unedited.
