# Taste

Direction reference for explore-design Stage 2. A starting point for a named direction, never a requirement to enlarge the brief.

Use for landing pages, portfolios, and marketing redesigns. It does not own
dashboards or product workflows. Infer direction from the brief; preserve existing
design decisions for scoped edits. Installation examples require stack verification.

Universal quality rules (states, contrast, motion safety, content honesty, launch basics) live in the floor, [implement's page-craft](../../../../implement/references/ui-build/page-craft.md); this direction adds only its look.

Read [medium and providers](../../medium-and-providers.md) for scope, provider selection,
previews, mock approval, and verification. Then load only the reference needed for
the current phase; do not read the full library for every task.
